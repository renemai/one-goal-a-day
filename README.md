# One Goal a Day — Realistic Prototype

Eine realistischere, mobile-first Version des Fußballspiels.

## Start
`index.html` direkt öffnen oder über GitHub Pages veröffentlichen.

## Enthalten
- realistischer Stadion-/Rasen-Look ohne externe Libraries
- Free-Kick-Szene mit Torwart und Mauer
- Drag/Swipe-Schuss
- Schusskraft und Richtung
- Torwartreaktion
- Score, Accuracy, Power und Ranking
- Bestscore via localStorage
- Share-Button
- responsive Mobile-Ansicht
- Demo-Freundesrangliste

## Noch für eine echte Version
- 3D-Fußball-/Stadion-Assets
- echte Ballphysik
- serverseitige Daily Challenge
- Accounts und globale Rangliste
- Anti-Cheat
- echte Freunde
- Push Notifications
- App Store / Google Play Wrapper
